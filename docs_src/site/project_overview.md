# Project Overview

Replication of Kelly, Malamud, and Zhou (2024), "The Virtue of Complexity in
Return Prediction" (*Journal of Finance* 79(1)), for UChicago FINM 32900, by
Ahmed Alahmadi and Jeff Key.

## Goal

The paper's central claim: a model that predicts the monthly market excess
return with a huge number of random features and only 12 months of training
data performs better out of sample as complexity grows, despite a terrible
out-of-sample R-squared. The project replicates the paper's Figures 7, 8,
and 11 at the 12-month training window, validates the results against
published anchor values with unit tests, reruns everything on data through
2024, and adds three extensions: a bonds study, an international equities
study, and a test of Nagel's (2025) critique that the strategy is
recency-weighted momentum in disguise.

## Data sources

| Source | Provider | Access | Used for |
|--------|----------|--------|----------|
| Predictor workbook | Amit Goyal's website | Public download | The 15 Goyal-Welch predictors and the market series |
| CRSP value-weighted index | WRDS | Account required (`WRDS_USERNAME` in `.env`) | Market excess return cross-check |
| Developed-ex-US market factors | Ken French data library | Public download | International equities extension |
| Bond return series | Goyal-Welch workbook | Public download | Bonds extension |

No raw data is stored in the repository; every input is re-pulled by the
pipeline (`doit`), and `_data/` is fully regenerable.

## Methodology

Predictors and returns are standardized by backward-looking volatility
(returns by a trailing 12-month window, predictors by an expanding window
with a 36-month burn-in), mapped through random Fourier features with
bandwidth gamma = 2, and fit by ridge regression with no intercept on
rolling 12-month windows. The ridge solve uses the dual form, so the only
linear system is 12 x 12 even at 12,000 features. Statistics are averaged
across 500 feature draws, following the paper. The estimation engine is a
reusable package, `voc` (see [the VoC API page](voc_api.md)); the exact
timing and standardization conventions are pinned in module docstrings and
enforced by tests.

## Results

The replicated figures, the extension studies, and the Nagel-critique
comparison live under Pipeline Charts, each with a take-away note; the
underlying tables are under Pipeline Dataframes. The guided-tour notebook
under Notebooks walks the whole pipeline end to end. The full write-up is
`reports/report_kmz.pdf`, built by `doit compile_latex_docs` with every
statistic generated by the pipeline.
