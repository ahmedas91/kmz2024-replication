## Description

One row per training-window lag (1 through 12): the estimated weight the VoC forecast places on each trailing standardized market return (`voc_lag_weight`, from the anatomy regression of the across-seed mean forecast on the trailing returns) next to the benchmark's linearly declining weight (`benchmark_weight`). The data behind `figure_nagel.png`. Built by `doit nagel`; keyed by the sample period.
